# Electrical Installations (Instalações Elétricas)

This repository contains the practical project files for the course in Electrical Installations, part of the Master's program in Electrical and Computer Engineering.

## Repository Contents

### IE_P1_G8 (Part 1)

This folder includes the first part of the project, which focuses on the estimation of electrical loads and the preparation of base plant layouts. The main components are:

- **Report**:  
  `IE_Parte1_G8_Relatorio.pdf` – Contains the detailed description of the methodologies and results for the first phase of the project.

- **Calculations**:  
  `IE_PotenciaPrevisivel_G8.xlsx` – Excel file with the predictive power calculations for the installation.

- **Plant Layouts**:  
  Contains AutoCAD drawings and other reference files for the electrical installation designs.

### IE_P2_G8 (Part 2)

This folder contains the second part of the project, which focuses on the design and optimization of the electrical system. It includes:

- **Report**:  
  `IE_P2_G8.pdf` – Detailed description of the methodologies, calculations, and conclusions for the second phase.

- **Subfolders**:
  - `AutoCAD`: Contains AutoCAD files for detailed electrical layouts.
  - `Excel Calculos`: Additional Excel files for detailed system calculations.
  - `Luminarias`: Specifications and details for lighting systems used in the project.
  - `Plantas`: Additional layout drawings for the project.
