# High Voltage Engineering

This repository contains three assignments for the course in High Voltage Engineering, part of the Master's program in Electrical and Computer Engineering.

## Repository Contents

### Trabalho 1: Experimental Determination of Disruption Voltages in Variable Air Gaps

The first assignment focuses on the experimental study of air gap breakdown voltages under varying distances. The key objectives include:
  
- **Data Collection**: Recording breakdown voltages for a range of air gap distances to analyze the relationship between the gap length and the breakdown voltage.

- **Analysis**: Using the gathered data to plot the breakdown voltage curves, compare them with theoretical models, and identify factors such as the influence of electrode geometry, environmental conditions, and gap uniformity.

The assignment combines theoretical analysis, experimental procedures, and data visualization, with all results compiled into a comprehensive report.

### Trabalho 2: Analysis of an Overhead Line Using Finite Element Software (QuickField)

The second assignment involves the simulation and analysis of an overhead transmission line using QuickField, a finite element analysis (FEA) software. Key objectives include:

1. **Modeling**: Developing a 2D model of an overhead transmission line in QuickField, including conductors, ground wires, and the surrounding medium.

2. **Simulation**:
   - Analyzing the electric field distribution around the conductors.
   - Calculating the potential gradients and corona onset voltage.
   - Evaluating the insulation levels and identifying critical points where field intensities are highest.

3. **Interpretation**: Comparing the simulation results with analytical calculations and discussing the implications for line design, such as ensuring adequate insulation and minimizing losses.

The report includes detailed simulation results, field plots, and technical insights into the behavior of the overhead line under typical operating conditions.

### Trabalho 3: Study of an Insulator String Using Finite Element Software (QuickField)

The third assignment focuses on the analysis of an insulator string for high-voltage applications using QuickField. Key objectives include:

1. **Model Development**: Creating a finite element model of a string of insulators, including the hardware connections and surrounding air.

2. **Simulation**:
   - Determining the voltage distribution across the insulators.
   - Identifying points of highest stress and evaluating the effectiveness of the grading rings, when present.

3. **Conclusions**: Based on the simulation results, proposing improvements for the insulator string design to enhance reliability and reduce stress concentrations.

The assignment integrates theoretical understanding with advanced simulation techniques, highlighting the role of modern software tools in high-voltage engineering.
