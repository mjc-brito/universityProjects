This is a QuickField example problem.
It consists of several files,
forming together a problem database.

File with the extension   .pbm
is a root file having references to all other files. 

The simulation results may be viewed
and analyzed using any installed version of QuickField,
including a free Student Edition.

Extract all files from this archive,
run QuickField and then open the .pbm file.

 
More details about using QuickField software
and free copy of QuickField Student edition
are available at http://www.quickfield.com
